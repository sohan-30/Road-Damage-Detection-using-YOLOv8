Research Proposal
4-Channel Early Fusion for Real-Time Road Damage Detection
Morphological Attention via Black-Hat Channel Augmentation on YOLOv8
1. Problem Statement
Road infrastructure damage — cracks, potholes, and surface deformation — causes significant economic and safety consequences globally. Automated detection using computer vision is a well-studied problem, but a critical gap remains: existing deep learning models either achieve high accuracy using slow segmentation architectures (U-Net, Mask R-CNN) or achieve real-time speeds using lightweight detectors (YOLO) but miss subtle, low-contrast damage like thin longitudinal cracks.

No existing work simultaneously addresses both constraints within a single architecture.

2. Core Idea: 4-Channel Early Fusion
We propose a minimal modification to the YOLOv8 input pipeline that augments the standard 3-channel RGB input with a 4th channel derived from classical morphological image processing — specifically the Black-Hat transform.

What is the Black-Hat Transform?
The Black-Hat operation is defined as:

Black-Hat(I) = Closing(I) − I
It isolates regions that are darker than their local surroundings — precisely the signature of thin cracks on light road surfaces. The result is a soft spatial attention map highlighting where damage is likely to exist.

The Early Fusion Architecture
Rather than using the Black-Hat mask as a preprocessing filter (which modifies or replaces the original image), we fuse it as an additional input channel alongside the intact RGB data:

Input Tensor: [R, G, B, BlackHat]  →  Modified YOLOv8 Conv1 (4-channel)
The first convolutional layer of YOLOv8 is modified from 3 to 4 input channels. The first 3 channels are initialized from ImageNet pretrained weights; the 4th channel is initialized from the grayscale-equivalent weights, giving it a meaningful starting prior.

3. Why This is Novel
Recent literature (2025) has explored hybrid approaches, but none match this specific combination:

Paper	Approach	Gap
CrackSense + U-Net (Mar 2025)	Preprocessing → modified RGB → U-Net	Sequential: loses original signal; too slow for real-time
MaskerTransformer (Jan 2025)	Mask R-CNN + Vision Transformer	Heavy architecture; not suitable for edge/dashcam deployment
This Work	RGB + BlackHat → 4-ch YOLOv8 (Early Fusion)	Preserves full original signal; real-time capable; single-stage

4. The Information-Theoretic Argument
A key theoretical claim of this work is grounded in information theory:

•	Prior approaches: Sequential preprocessing pipelines modify the original RGB before feeding it to the network. Any such transformation is lossy unless perfectly invertible.
•	Our approach: Our input is a strict superset — we feed the original, unmodified RGB plus the derived mask. The network therefore has access to at least as much information as any preprocessing-only pipeline starting from the same source image.
•	Important caveat: More input information does not automatically yield better performance — but it establishes an upper bound. The empirical ablation studies confirm whether the network exploits this additional channel effectively.

5. Experimental Plan
Dataset
•	CRDDC2022 (Crowd-sourced Road Damage Detection Challenge 2022) — multi-country dataset with 4 damage classes: longitudinal cracks (D10), transverse cracks (D20), alligator cracking (D40), and potholes (D40)

Ablation Studies
Experiment	Purpose
YOLOv8s baseline (3-channel RGB)	Control — standard model
YOLOv8s with 4-channel input (k=9)	Small kernel — sensitive to hairline cracks
YOLOv8s with 4-channel input (k=17)	Medium kernel — standard cracks
YOLOv8s with 4-channel input (k=25)	Large kernel — wide damage, alligator patterns
YOLOv8s with Gaussian blur before BlackHat	Effect of noise suppression on mask quality

Evaluation Metrics
•	Overall mAP@0.5 and mAP@0.5:0.95
•	Per-class AP — expected gains primarily on D10 (longitudinal) and D20 (transverse)
•	End-to-end inference FPS including preprocessing latency
•	Qualitative visualization of 4th channel activations on hard examples

6. Expected Contributions
•	Technical: A minimal, architecture-agnostic input modification applicable to any YOLO variant
•	Theoretical: Formal information-theoretic justification for early fusion over sequential preprocessing
•	Empirical: Empirical evidence that classical morphological priors improve fine-grained crack detection in a fast single-stage detector
•	Practical: A kernel-size ablation study characterizing the sensitivity of the Black-Hat channel to different damage scales
